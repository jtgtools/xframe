# Frame3DD Reference Data

This directory contains reproducible oracle inputs and outputs generated by an external Frame3DD `20140514+` Linux executable. The executable and Frame3DD source are intentionally not distributed with xframe.

## Provenance

Expected executable SHA-256:

```text
53b1dc6628424b156e491e3205f13d58a0e325e33e4746d225b456ab85ac5275
```

Regenerate every reference with:

```bash
FRAME3DD_BIN=/absolute/path/to/frame3dd node scripts/regenerate-frame3dd-reference.mjs
```

The script verifies the executable hash before execution. Generated directories contain the exact `.3dd` input, raw `.out` output, Frame3DD CSV output, debug matrices, and parsed `reference.json` with units, hashes, command arguments, and tolerances. Raw Frame3DD text and matrix headers include an execution timestamp; parsed numerical reference values are deterministic for the recorded executable.

## Cases

- `cantilever-euler`: one frame, Euler-Bernoulli stiffness, six static cases.
- `cantilever-timoshenko`: one frame, shear-flexible stiffness, six static cases.
- `frame-chain-euler`: two frames with distinct properties, two direct 12×12 element matrices, one direct 18×18 assembled matrix, nodal results, element end forces, and reactions.
- `triangular-truss`: three pure-axial xframe trusses compared with Frame3DD's documented tiny-bending truss approximation, including prescribed support movement.

Geometric stiffness is disabled in every oracle case.

## Oracle limits

The reference is used for independent comparison, not as implementation source. Frame3DD does not define xframe springs, exact vector rigid offsets, general affine constraints, rigid-diaphragm expansion, result combinations, streaming envelopes, JSON artifacts, identifier policy, or truss-only active-DOF topology. Those features are verified by closed forms, algebraic identities, and adversarial tests.

Two Frame3DD point-force displacement discrepancies are isolated in the executable test and replaced by independent closed forms: reversed axial point-force interpolation and exchanged Timoshenko shear parameters between the two transverse bending planes. Common end forces and reactions remain compared. Raw outputs are preserved unchanged.
